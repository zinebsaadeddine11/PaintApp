# PaintJava

Petite interface graphique Java Swing inspirée de Microsoft Paint.

Fonctions disponibles :

- crayon et gomme ;
- ligne, rectangle et ellipse ;
- choix de couleur et de taille de trait ;
- annuler/rétablir ;
- effacer la toile ;
- ouvrir une image et enregistrer au format PNG.

## Lancer l'application

Depuis le dossier du projet :

```powershell
.\run.bat
```

Ou manuellement :

```powershell
javac -d out src\main\java\com\example\paint\*.java
java -cp out com.example.paint.PaintApp
```
